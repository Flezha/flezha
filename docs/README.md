# Flezha documentation

The published documentation lives in [`public/`](public/). It starts at
[What is Flezha](public/getting_started/what_is_flezha.md), and its sidebar, the order and
grouping of every page, is the `docs` configuration in `mix.exs`. `mix docs` builds it into
`doc/`, with the tutorials as a second site in `doc/tutorials/`.

Pages for people who build Flezha rather than use it live in [`internal/`](internal/), one
line each in [`internal/README.md`](internal/README.md).
