# The controller's published consumer surface.
#
# Every function here takes a Flezha.Service.CallerContext as its LAST argument,
# authorizes through it before any effect, and answers data rather than text
# formatted for a terminal. A consumer of this controller calls these and
# nothing else; docs/api/consumers/flezha_ui.txt records what one consumer
# actually calls today, and the gap between the two files is what phase 3 of
# publish-a-controller-consumer-api closes.
#
# Hand-maintained, and test/flezha/api/consumer_surface_test.exs holds it to
# three things: every line resolves against this tree, every line is on `Flezha`
# or a `Flezha.Service.*` module, and a name is retired only together with the
# manifests that spell it.
#
# TWO NAMES ARE CALLABLE WITHOUT A CONTEXT, AND ONLY TWO. A consumer verifies a
# token and reads the enforcement posture BEFORE it holds a context, because
# their answers are what a context is built from; they cannot be authorized by
# the thing they bootstrap. Both are read-only. Nothing else may join them.
#
#   Flezha.AuthZ.TokenStore.verify/1
#   Flezha.AuthZ.enforcement_posture/0
#
# Two public functions on the modules below are NOT on this surface, because
# they take no context and no consumer calls them:
# `Flezha.Service.Controller.local_recovery_snapshot/1` is the remote half of
# one fan-out, and `Flezha.Service.PluginManager.target_namespace/1` is the
# scope resolver the CLI shares with the published half of that module.
