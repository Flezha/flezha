flz audit read - A kind's records from every controller, newest first, each naming its `node`.

Usage: flz audit read [<file>] [--source <source>] [--name <name>] [--since <microseconds>] [--until <microseconds>] [--limit <count>] [--before <cursor>] [--node <controller>]

OPTIONS:
    --source <source>        Match records whose source is this.
    --name <name>            Match records whose name is this.
    --since <microseconds>   Match records written at or after this wall-clock
                             time.
    --until <microseconds>   Match records written at or before this wall-clock
                             time.
    --limit <count>          Return at most this many records (default 100, at
                             most 1000).
    --before <cursor>        Continue from the `next` cursor a previous read
                             printed.
    --node <controller>      Only this controller (with --file, its file; with
                             rotate, rotate it alone).
    --token <token>          The caller's token (default: FLEZHA_TOKEN).
    --help | -h              Print this help.
    --output | -o text|json  Output format (default: text).
    --json                   The same as --output json.

Without a file the records of every controller are newest first, and a next
cursor is printed while more are older; pass it back with --before. A <file>
with --node reads that one file, oldest first. With --json the answer is one
JSON object.
