flz state - Per-Cell state inspection and time-travel queries.

USAGE:
    flz state <COMMAND>

COMMANDS:
    get        The CURRENT in-memory state of live Cells, as JSON.
    list       One row per Cell of `relay_class` with persisted state.
    at         One Cell's state as of `target`, from its write-ahead log.
    rotate     Force a compaction of one Cell.
    retention  Retain `relay_class`'s write-ahead history for `hours`.
    delete     Hard-delete one Cell's persisted state.
    outbox     One Cell's outbox, with its cursors, epoch and lag.
    journal    One instance's task journal, in append order.
    inbox      An instance's durable input log, record by record.
    help       Show this help message.

EXAMPLES:
    flz state get MarketRelay/OhlcTasklet/M1
    flz state get MarketRelay/OhlcTasklet --output json
    flz state list MarketRelay
    flz state at MarketRelay/OhlcTasklet/M1 12345
    flz state at MarketRelay/OhlcTasklet/M1 2026-05-01T12:00:00Z
    flz state rotate MarketRelay/OhlcTasklet/M1
    flz state retention MarketRelay 6
    flz state delete MarketRelay/OhlcTasklet/M1
    flz state outbox MarketRelay/OhlcTasklet/M1
    flz state journal etl-job-42
    flz state inbox chat-session-7
