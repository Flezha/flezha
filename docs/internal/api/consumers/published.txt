# The controller's published consumer surface.
#
# Every function here takes a Flezha.Service.CallerContext as its LAST argument,
# authorizes through it before any effect, and answers data rather than text
# formatted for a terminal. A consumer of this controller calls these and
# nothing else; docs/internal/api/consumers/flezha_console.txt records what one consumer
# actually calls, and every call recorded there is on this list.
#
# Hand-maintained, and test/flezha/api/consumer_surface_test.exs holds it to
# three things: every line resolves against this tree, every line is on `Flezha`
# or a `Flezha.Service.*` module, and a name is retired only together with the
# manifests that spell it.
#
# THREE NAMES ARE CALLABLE WITHOUT A CONTEXT, AND ONLY THREE. A consumer
# verifies a token and reads the enforcement posture BEFORE it holds a context,
# because their answers are what a context is built from; they cannot be
# authorized by the thing they bootstrap. The door's context/2 joins them
# because it IS that build: the one bad-token rule every surface keeps, over
# verify/1. All three are read-only. Nothing else may join them.
#
#   Flezha.AuthZ.TokenStore.verify/1
#   Flezha.AuthZ.enforcement_posture/0
#   Flezha.Service.Admin.context/2
#
# One public function on the modules below is NOT on this surface, because it
# takes no context and no consumer calls it:
# `Flezha.Service.Controller.local_recovery_snapshot/1` is the remote half of
# one fan-out.
