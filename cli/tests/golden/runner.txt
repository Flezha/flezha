flz runner - Runner management commands.

USAGE:
    flz runner <COMMAND>

COMMANDS:
    list     Every runner serving `namespace`, anywhere in the cluster.
    check    Report whether a runner on this host can reach a controller.
    drop     Drop the runner `runner_id` serving `namespace`.
    dropped  The drop marks standing in `namespace`, oldest first.
    readmit  Lift the drop mark on the runner `stable_id` in `namespace`.
    help     Show this help message.

Use 'flz runner <COMMAND> --help' for more information on a specific command.
