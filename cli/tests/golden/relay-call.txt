flz relay call - Call the entry channel `channel` of `relay_id` with `value`.

Usage: flz relay call <relay_id> [--text | -t <payload>] [--arg <name=value>] [--channel | -c <ch>] [--answer-channel <ch>] [--key <key>] [--timeout <ms>] [--namespace | -n <namespace>]

OPTIONS:
    --text | -t <payload>         The payload, sent as written.
    --arg <name=value>            One field of a JSON input, typed by the
                                  channel's schema; repeat it for each field.
    --channel | -c <ch>           The entry channel; the first when empty.
    --answer-channel <ch>         The channel whose output answers (default: the
                                  first output).
    --key <key>                   The key whose member of a partition group
                                  takes the input.
    --timeout <ms>                How long the relay has to answer, in ms
                                  (default 30000).
    --namespace | -n <namespace>  The namespace (default: default).
    --token <token>               The caller's token (default: FLEZHA_TOKEN).
    --help | -h                   Print this help.
    --output | -o text|json       Output format (default: text).
    --json                        The same as --output json.

OUTPUT:
    The answer and a newline: the first output the input caused, or its first
    on the answer channel when one is named, as the relay's API reads it. A
    channel that does not answer prints `accepted`. The output also reaches
    the relay's plugins and listeners. A failure is printed on stderr with its
    code and exits by its class: call.timeout 7, a denied call 4,
    relay.not_found 5, api.input_invalid 2.

EXAMPLES:
    flz relay call echo --text hello
    flz relay call orders-eu --channel place --arg pair=EUR/USD --arg amount=1000
    flz relay call prices --key EURUSD --text '{"pair":"EURUSD"}'
    flz relay call quoter --text EUR/USD --answer-channel quotes
    flz relay call slow --text x --timeout 100
