flz namespace - Namespace management commands.

USAGE:
    flz namespace <COMMAND>

COMMANDS:
    list           The namespaces in the durable catalog the caller may be
                   shown, and the controllers each runs on.
    create         Create a namespace.
    delete         Delete a namespace and the quota counters keyed on it.
    show           One namespace record.
    set-quota      Replace the namespace's quota overrides.
    set-migration  Set how the namespace's hub moves its relays, `cold` or
                   `hot`.
    help           Show this help message.

create and set-quota take each quota as --X<quota>=<value>.

Quota fields: max_relays, max_cells_per_relay, max_mailbox_bytes_total,
              max_message_rate_per_second, max_state_bytes, max_runners
