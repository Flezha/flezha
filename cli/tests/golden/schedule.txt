flz schedule - Cron-scheduled steps relay spawns.

USAGE:
    flz schedule <COMMAND>

COMMANDS:
    add     Store a schedule and assert it on the hub.
    list    Every stored schedule, by name, with what the hub holds for it.
    remove  Forget a schedule and retract it from the hub.
    run     Fire a schedule once, now.
    help    Show this help message.

add refuses a factory a connected runner announced as flow. run fires one
instance at once with the stored config, judged as relay.start in the
schedule's namespace.

EXAMPLES:
    flz schedule add digest --cron "0 8 * * *" --tz Europe/Tallinn --factory ai_digest
    flz schedule add nightly --cron "0 2 * * *" --tz UTC --factory report --text '{"day":"today"}' --channel requests
    flz schedule list
    flz schedule run digest
