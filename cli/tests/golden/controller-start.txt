flz controller start - Start the flezha controller.

Usage: flz controller start [--mode | -m attached|daemon|attached_iex|daemon_iex]

OPTIONS:
    --mode | -m attached|daemon|attached_iex|daemon_iex
                             How the controller runs (default: attached).
    --token <token>          The caller's token (default: FLEZHA_TOKEN).
    --help | -h              Print this help.
    --output | -o text|json  Output format (default: text).
    --json                   The same as --output json.

EXAMPLES:
    flz controller start
    flz controller start --mode daemon
    flz controller start -m attached_iex
