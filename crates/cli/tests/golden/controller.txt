flz controller - Controller management commands.

USAGE:
    flz controller <COMMAND>

COMMANDS:
    start    Start the flezha controller.
    stop     Drain this controller and stop it.
    status   Each controller's status, one row per controller: node, clock,
             shutdown and durability.
    list     Every controller the cluster directory lists, the one that answered
             first.
    mem-top  One snapshot of each controller's memory hot spots, one row per
             controller.
    help     Show this help message.
