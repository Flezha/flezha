# New issues found during this campaign

Found while working, **not fixed**. This file is an inbox, not a ledger: at
campaign reset every row is drained into `docs/known-bugs.md`, which is the
standing list. Nothing lives in both.

A row is written down and moved on from. It is fixed on sight only when it
blocks the item in hand, and then it is still written here, marked fixed, with
the reason it blocked.

Same shape as a known-bugs row, so it moves without being rewritten:

```markdown
### W-000: one line naming the defect, not the fix

- **Date**: YYYY-MM-DD
- **Severity**: P1 | P2 | P3 | P4
- **Status**: open
- **Found while**: <item id>
- **Where**: file and function.
- **Description**: what is wrong, and one line on why it matters.
- **Reproduce**: the command and what it printed, or `_not written yet._`
```
